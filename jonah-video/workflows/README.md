# 多代理制作流程（Workflow 脚本）

这些脚本由 Claude Code 的 Workflow 工具运行，用多个代理并行完成制作和审查。换一个故事时，基本只需要改脚本里的场景说明（`BRIEFS`）和路径。

| 脚本 | 作用 | 用法 |
| --- | --- | --- |
| `script_review.js` | 剧本三方审稿：圣经准确性、儿童适宜性与口语、多音字读音风险 | 写好 `story.py` 后运行 |
| `characters_props.js` | 建角色库和道具库：构建 → 美术总监审稿 → 修改 | 新故事需要新角色或道具时，改任务说明后运行 |
| `audio_sfx_music.js` | 音效库和配乐：构建 → 技术/音乐审查 → 修改 | 新故事需要新配乐主题或音效时运行 |
| `scenes.js` | 每个场景：绘制 → 独立审稿 → 修改；`BRIEFS` 里写每个场景的说明和可复用的旧场景 | 以场景 id 列表作为 `args`，分几批并行运行 |
| `film_review.js` | 成片审片：分段画面审查 + 音频审查 → 每个问题独立复核 → 按场景修改 | 合成出成片后运行；`args.segments` 给出分段的场景 id |
| `reverify.js` | 逐条复查已确认的问题是否修好，并做回归检查 | 修改并重新合成后运行，`args: {"count": N, "sweeps": [[改过的场景 id…]]}` |

经验规则已写进 `../ART_GUIDE.md` 和这些脚本的提示词里，例如：不同姿势之间不用交叉淡化，用硬切加"挤压-弹跳"掩盖；走路要"脚踩实地"不滑步；镜头移动限速；转场时避免两个主角重影；读音要查词典里的多音字。
