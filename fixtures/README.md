# Cargo compatibility fixtures

`cargo-contract.json` is generated, not hand-authored: run `node scripts/cargo-fixtures.cjs` from the repository root. `--check` compares exact generated bytes and bundled content without modifying files.

The fixture stores the SHA-256 of the unchanged `storm-engine.js`, 8,192 combinations (64 cargo subsets × 64 delivered subsets × two capacities), and 14 invalid/order-sensitive cases. This deliberately includes unreachable delivered sets so validation order remains a full function contract. Run Swift verification to compare every expected result, including omitted weight/reason fields, with `CargoRules.check`.

Trip budgets, state transitions, independent solvability, persistence and UI are separate tests. The baseline web app's delivery commits after a timer; the native app commits before presentation for deterministic interruption recovery. This timing choice is documented in `apps/ios/README.md` and is not represented as a JS scene-timing equivalence test.
